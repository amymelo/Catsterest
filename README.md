# 📖 Sobre o projeto

O **Catsterest** é um projeto desenvolvido inteiramente por mim como forma de praticar desenvolvimento Front-end e criar algo leve, divertido e visualmente agradável.

A proposta não é ser uma rede social completa, mas sim um pequeno projeto para entretenimento, inspirado em plataformas de compartilhamento de conteúdo, trazendo uma experiência voltada para quem ama gatos.

Mesmo sendo um projeto simples, ele foi desenvolvido com dedicação, buscando uma boa organização, interface agradável e uma experiência divertida para quem o acessa.

# 💻 Como executar

Clone o repositório:

```bash
git clone https://github.com/amymelo/Catsterest.git
```

Entre na pasta:

```bash
cd Catsterest
```

Abra o arquivo:

```text
index.html
```

Ou utilize uma extensão como o **Live Server** no Visual Studio Code.
